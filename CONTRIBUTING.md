# Contributing

Please open an issue describing the behavior and a small fictional example before a large change. Do not upload private configuration, real credentials, customer data, or private network captures.

Use Node.js 22.12+, run npm ci, then the validation commands in the README. Keep examples deterministic and update all five README translations when behavior changes. Follow the existing formatting with npm run format.

Pull requests should describe the observable change, include a focused test for behavioral fixes, and keep generated build output out of Git.
